# Ӟеч-а бур-а, удмурт кыл?

Мобильное приложение для изучения удмуртского языка детьми 5–10 лет. Команда **Udmurt.Dev**: Ребро Александр, Щенин Андрей, Григорьев Ростислав, Килеев Захар.

- 91 слово и фраза в 12 темах: картинка, перевод, транскрипция, удмуртская озвучка
- Путешествие по Удмуртии: 12 городов от Ижкара до Иднакара
- 6 игр: «Выбери перевод», «Найди лишнее», «Сортировка», «Найди пару», «Собери слово», «Правда/Ложь»
- Медвежонок-первоклассник Гондырпи: экскурсия и подсказки голосом
- Профили с паролем из картинок, статистика, отчёт для родителей и учителя
- Android 8.0+, полностью офлайн

**Попробовать без установки:** скачайте `demo/index.html` и откройте в браузере.

## Структура

- `android/UdmurtKyl` — Android-проект (Java, WebView), открывается в Android Studio
- `web/app/src` — исходники интерфейса: экраны, игры, словарь, рисунки; картинки и озвучка упакованы в `media.zip` (распакуйте перед сборкой)
- `web/tools` — сборка интерфейса в один файл и озвучка слов
- `demo/index.html` — собранное приложение

## Сборка APK

Мобильное приложение для изучения удмуртского языка детьми 5–10 лет. Android 8.0+ (minSdk 26), работает без интернета, размер APK ≈ 5 МБ.

## Как собрать APK (Android Studio)

1. Установите Android Studio (Koala или новее). JDK 17 идёт в комплекте.
2. **File → Open** → выберите папку `android/UdmurtKyl`.
3. Дождитесь окончания Gradle Sync. Для первой сборки нужен интернет: скачаются Gradle 8.7, Android Gradle Plugin 8.5.2 и библиотека `androidx.webkit`.
4. **Build → Build App Bundle(s) / APK(s) → Build APK(s)**.
5. Готовый файл: `android/UdmurtKyl/app/build/outputs/apk/debug/app-debug.apk`. Его можно скинуть на телефон и установить (разрешите «установку из неизвестных источников»).

Из командной строки: `cd android/UdmurtKyl && ./gradlew assembleDebug` (Windows: `gradlew.bat assembleDebug`). Если Gradle попросит Android SDK, создайте файл `local.properties` со строкой `sdk.dir=ПУТЬ_К_SDK` или один раз откройте проект в Android Studio.

`assembleRelease` тоже собирается и подписывается отладочным ключом, этого хватает для показа на хакатоне.

## Как устроено

- `app/src/main/assets/www/index.html` — всё приложение в одном файле: интерфейс, 91 слово и фраза, 149 картинок, шрифты, 132 озвученные фразы (удмуртский голос нейросети Meta MMS-TTS, лицензия CC BY-NC 4.0 — для учебного некоммерческого проекта). Ничего не грузится из сети, в манифесте нет разрешения INTERNET.
- `MainActivity.java` — полноэкранный WebView. Файлы отдаются через `WebViewAssetLoader` с защищённого адреса `https://appassets.androidplatform.net`, поэтому `localStorage` надёжно хранит профили, прогресс и настройки между запусками.
- Мост `AndroidBridge` подключает нативные функции:
  - `speak()` — озвучка через системный TextToSpeech с русским голосом, ударение передаётся знаком ́;
  - `scheduleReminder()` / `cancelReminder()` — ежедневное локальное уведомление через AlarmManager, на Android 13+ запрашивается разрешение;
  - `share()` — отправить отчёт родителю или учителю через любой мессенджер;
  - `requestLocation()` — разрешение на геолокацию для экрана «Далеко ли ты от Ижкара».
- Системная кнопка «Назад» сначала закрывает окна внутри приложения и возвращает на предыдущий экран, а с главного экрана выходит.

## Как поменять слова или картинки

Исходники лежат в `web/app/src` (если открыть `demo/index.html` в браузере, приложение запустится и без сборки):
- `data.js` — темы и слова;
- `app.js` — логика экранов и игр;
- `art.js` — собственные рисунки (платье, фартук, платок, ягоды, флаг, орнамент);
- `mascot.js` — медвежонок Гондырпи (5 поз, 4 эмоции);
- `journey.js` — путешествие по Удмуртии: 12 остановок, факты, реплики медвежонка;
- `audio/` — готовая озвучка; скрипт `web/tools/synth.py` озвучивает новые слова моделью MMS udm (нужен файл model.onnx).
- `styles.css` — оформление;
- `img/` — картинки.

После правки выполните `python3 web/tools/build.py`. Скрипт соберёт один файл и сам положит его в `android/UdmurtKyl/app/src/main/assets/www/index.html`, затем пересоберите APK. Нужен Python 3. Картинки уже лежат в `img/`, их скачивать не надо.
